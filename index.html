Stroke Pathway using WOYZ

Shared mobile and desktop stroke-pathway prototype source. The application code now lives as a Vinext/Next project with /mobile, /admin, and an authenticated case API.

Open repository Start here README

This GitHub Pages page is a source landing page. The current app is not a plain static site; run it with Node/Vinext locally or deploy it to an app runtime.

Local Run

  • Install Node.js 22.13 or newer.
  • Run npm run install:ci.
  • Run npm run build.
  • Apply the local D1 schema from drizzle/0000_dusty_silhouette.sql.
  • Run npm run dev and open /mobile or /admin.
